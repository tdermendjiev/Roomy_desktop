It knows where every tool hides its data

Generic cleaners see a folder called "Application Support". Roomy knows that Cursor's CachedData is safe to drop, that Claude Code's transcripts are not, and that a Hugging Face hub folder is a model store you can re-download in a minute.

  • Local models: Ollama, LM Studio, Hugging Face, llama.cpp, PyTorch Hub, Whisper
  • Editor and app caches: Cursor, Claude desktop, Windsurf, Kiro, Trae, plus MCP server caches and Playwright browsers
  • Agent history: Claude Code, Codex, Gemini CLI, OpenCode, Goose, Cline, Roo

Thirty prototypes, one afternoon, 14 GB of node_modules

When starting a project costs one prompt, you start a lot of them. Each one pulls its own dependencies. Roomy reads the git history and file dates of every project, sorts the ones you abandoned to the top, and pre-selects their artifacts for cleanup.

  • Projects classified Active, Recent, Inactive or Dormant from commits and file dates
  • Claude Code session transcripts are grouped per project and aged the same way
  • Your source code is never touched, only the regenerable folders inside each project

Your chat history is not a cache

A model can be pulled again. An agent transcript cannot. Roomy puts every item in one of three tiers, keeps Irreversible items out of bulk selection, and tells you in plain words what you get back and how.

  • Safe: models, caches, VM images. Re-downloaded or rebuilt on next use
  • Review: vector stores and app data that mixes caches with your content
  • Irreversible: session transcripts, checkpoints, file history. Never bulk-selected

Nothing leaves your Mac Roomy reads your filesystem and sends nothing anywhere. No account, no telemetry, no cloud. Your transcripts, prompts and code stay exactly as private as they were.

Will it delete my Cursor or Claude chat history?

Not unless you pick it on purpose. Chat databases and settings are never listed. Agent transcripts are listed but marked Irreversible, excluded from bulk selection, and shown with a last-session date so you can keep the recent ones.

Is deleting Ollama or Hugging Face models safe?

Yes, in the sense that any model can be downloaded again. Roomy marks them Safe and shows the pull command. It is slow to recover from, so you decide.

I do not really know what node_modules is. Is this for me?

Yes. Every item has a plain-language description and a restore hint. If a folder regenerates when you next open the project, Roomy says so.

Why is Cursor using 18 GB?

Caches, per-workspace state for every project you ever opened, and web storage. We wrote it up: Why Cursor uses so much disk space.

Does Roomy send anything to the cloud?

No. It reads your disk locally and has no network features. See also where Claude Code stores its data and where Ollama stores models.
